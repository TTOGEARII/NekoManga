# NekoManga (=^･ω･^=)

흑백 만화에 마법을 부리는 올인원 데스크톱 앱.
이미지를 끌어다 놓고 버튼 하나만 누르면 — 번역·검열 제거·채색까지 알아서 해줍니다.

- 💬 **번역 + 식자** — 말풍선을 읽고(manga-ocr) 번역해 깔끔하게 다시 써넣어요
  - 번역 엔진 선택: **Google**(무료) · **DeepL** · **DeepSeek** · **Grok** — AI 엔진은 문맥을 살려 말투가 자연스러워요
  - 일본식 세로 말풍선도 한국어 가독성에 맞게 가로로, 단어가 중간에 끊기지 않게 배치돼요
- 🙈 **검열 제거** — 전용 학습 AI가 검은 막대·흰 막대·모자이크를 찾고, 복원 전에 **직접 확인·보정**할 수 있어요
  - 감지 → 검토 창에서 놓친 곳을 칠하거나 잘못 잡힌 곳을 지움 → 복원
  - 복원 방식 4가지: **기본**(만화·애니 학습 LaMa, 빠름) / **엔진 LaMa**(GPU) / **재생성**(SDXL, 내장 레시피) / **커스텀 ComfyUI**(내가 만든 워크플로)
  - 검토 창에서 고친 마스크는 학습 재료로 쌓이고, 원하면 앱 안에서 **반자동 자가 학습**으로 감지 모델을 내 작품에 맞춰 갈 수 있어요
- 🎨 **자동 채색** — 흑백 원고를 AI가 풀컬러로
  - **컬러 표지를 등록하면** 캐릭터 머리·눈·의상 색을 표지와 똑같이 맞춰줘요
  - ComfyUI 화면을 앱에서 바로 열고, 거기서 만든 워크플로(API JSON)를 채색·검열 제거에 끼울 수 있어요

모든 AI 엔진은 **앱이 알아서 설치하고, 켜고, 꺼요** — 따로 실행하거나 관리할 프로그램이 없습니다.
번역과 검열 제거(기본)는 작은 내장 모델(약 0.8GB)만 받으면 바로 쓸 수 있고,
채색까지 쓰려면 첫 실행 안내에서 **채색 엔진(약 20GB)을 선택 설치**하면 끝이에요.
설치할 때 PC를 점검해서 그래픽카드에 맞는 엔진을 고르고, 드라이버·런타임이 모자라면 받을 곳을 바로 알려줘요.
**VRAM·RAM에 맞춰 해상도·메모리 옵션도 자동으로 맞춰** 주니 따로 만질 게 없어요.

## 설치

[최신 버전 받기](https://github.com/TTOGEARII/NekoManga/releases/latest) — `NekoManga-win-Setup.exe`를 받아 실행하세요.
이후 새 버전이 나오면 앱이 알아서 알려주고, 버튼 한 번으로 업데이트됩니다.

### PC 사양

| | 최소 (번역·식자·검열 제거) | 권장 (채색·재생성까지) |
|---|---|---|
| OS | Windows 10 64비트 | Windows 10/11 64비트 (AMD는 Windows 11) |
| CPU | 쿼드코어 이상 | 6코어 이상 |
| RAM | 8GB | **32GB** (16GB 미만이면 앱이 엔진 미리 켜기를 자동으로 꺼요) |
| GPU | 없어도 동작해요 | **NVIDIA RTX 20 이상** 또는 **AMD Radeon RX 6000 이상**, VRAM 8GB 이상 (GTX 10 이하는 구형 엔진으로 자동 설치, 느려요) |
| 디스크 | 2GB | **25GB 이상** |
| 인터넷 | 최초 모델 다운로드(0.8GB) | 최초 모델 다운로드(약 20GB) |

- NVIDIA는 드라이버 **580 이상**(RTX 20 이상) 또는 528 이상(GTX 10 이하), Visual C++ 2015–2022 x64 런타임이 필요해요 — 설치 창이 검사해서 부족하면 받을 곳을 알려줘요.
- AMD는 ComfyUI 공식 ROCm 포터블을 받아요(초기 지원). NVIDIA보다 느리거나 일부 노드가 안 될 수 있어요.

처리 속도 참고 (RTX 2070 SUPER 기준): 번역+식자 페이지당 약 15초,
검열 제거 약 15초, 자동 채색 약 2분 30초.

## 사용법

1. 만화 이미지(또는 폴더)를 창에 끌어다 놓아요 — 이름 순서(1, 2, 10)로 자동 정렬돼요
2. 원하는 기능 토글을 켜요
3. **✦ 시작!** — 검열 제거를 켰으면 감지가 끝난 뒤 **검열 마스크 검토 창**이 떠요. 빨간 곳이 지워지니 놓친 검열은 칠하고, 잘못 잡힌 곳은 지우개로 지운 뒤 [검열 제거 시작]
4. 끝나면 원본 폴더 옆 `폴더명_neko`에 저장돼요 — 한 장씩 끝날 때마다 목록 썸네일과 미리보기가 결과물로 바뀌어요

마음에 안 드는 부분은 **결과 보기·수정** 창에서 직접 고칠 수 있어요:

- 🙈 **검열 지우기** — 자동 감지가 놓친 검열을 꼭짓점 클릭이나 브러시로 집어 지워요 (기본 LaMa / 엔진 LaMa / 재생성 / 커스텀 중 선택)
- 💬 **식자 다시 하기** — 말풍선 위 글자를 그 자리에서 바로 고치고, 옮기고, 크기를 바꿔요 (글꼴·색도 변경)

채색 품질, 검열 감지·복원 방식, 번역 엔진, 글꼴 같은 세부 조절은 ⚙ 설정에서 할 수 있어요.
더 좋은 채색 모델이 나오면 설정 → 엔진에서 파일이나 주소로 받아 바꿔 끼울 수 있고,
PC를 바꿨다면 설정 → 엔진의 **[이 PC에 맞게 조정]**으로 해상도·메모리 옵션을 다시 맞출 수 있어요.

## ComfyUI를 쓰는 분께

- 설정 → 엔진 → **ComfyUI 화면 열기**로 앱이 내장한 ComfyUI를 브라우저에서 열 수 있어요 (모델·노드·큐를 앱과 공유).
- **내장 재생성 레시피를 ComfyUI에 넣기**로 앱의 검열 제거 워크플로를 ComfyUI 워크플로 목록에 복사해 출발점으로 쓰세요.
- 고친 워크플로를 **Export (API)** 로 저장하면 검열 제거(커스텀 ComfyUI)나 채색(채색 커스텀)에 그대로 끼울 수 있어요.
  규칙은 둘뿐: LoadImage 하나(앱이 원고를 넣어요, 검열 제거면 알파 = 마스크), SaveImage 하나(결과).
