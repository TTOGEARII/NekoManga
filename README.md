# NekoManga (=^･ω･^=)

흑백 만화에 마법을 부리는 올인원 데스크톱 앱.
이미지를 끌어다 놓고 버튼 하나만 누르면 — 번역·검열 제거·채색까지 알아서 해줍니다.

- 💬 **번역 + 식자** — 말풍선을 읽고 번역해 깔끔하게 다시 써넣어요
  - 번역 엔진 선택: **Google**(무료) · **DeepL** · **DeepSeek** · **Grok** — AI 엔진은 문맥을 살려 말투가 자연스러워요
  - 일본식 세로 말풍선도 한국어 가독성에 맞게 가로로, 단어가 중간에 끊기지 않게 배치돼요
- 🙈 **검열 제거** — 검은 막대·흰 막대·모자이크를 찾아 감쪽같이 복원해요
  - 세 가지 방식: **기본**(빠름) / **엔진 LaMa**(GPU, 부드러운 복원) / **강력**(AI가 그 자리를 다시 그림)
- 🎨 **자동 채색** — 흑백 원고를 AI가 풀컬러로
  - **컬러 표지를 등록하면** 캐릭터 머리·눈·의상 색을 표지와 똑같이 맞춰줘요

모든 AI 엔진은 **앱이 알아서 설치하고, 켜고, 꺼요** — 따로 실행하거나 관리할 프로그램이 없습니다.
번역과 기본 검열 제거는 작은 내장 모델(약 0.8GB)만 받으면 바로 쓸 수 있고,
채색·강력 검열 제거까지 쓰려면 첫 실행 안내에서 **채색 엔진(약 20GB)을 선택 설치**하면 끝이에요.
설치 후에는 앱을 켤 때 엔진도 미리 준비돼서 기다림 없이 바로 작업할 수 있어요.

## 설치

[최신 버전 받기](https://github.com/TTOGEARII/NekoManga/releases/latest) — `NekoManga-win-Setup.exe`를 받아 실행하세요.
이후 새 버전이 나오면 앱이 알아서 알려주고, 버튼 한 번으로 업데이트됩니다.

### PC 사양

| | 최소 (번역·식자·기본 검열 제거) | 권장 (채색·강력 검열 제거까지) |
|---|---|---|
| OS | Windows 10 64비트 | Windows 10/11 64비트 |
| CPU | 쿼드코어 이상 | 6코어 이상 |
| RAM | 8GB | **32GB** (16GB라면 설정 → 엔진에서 "작업이 끝나도 엔진을 꺼두지 않기"를 꺼주세요) |
| GPU | 없어도 동작해요 | **NVIDIA 그래픽카드, VRAM 8GB 이상** |
| 디스크 | 2GB | **25GB 이상** |
| 인터넷 | 최초 모델 다운로드(0.8GB) | 최초 모델 다운로드(약 15GB) |

처리 속도 참고 (RTX 2070 SUPER 기준): 번역+식자 페이지당 약 15초,
검열 제거 약 15초, 자동 채색 약 2분 30초.

## 사용법

1. 만화 이미지(또는 폴더)를 창에 끌어다 놓아요
2. 원하는 기능 토글을 켜요
3. **✦ 시작!** — 끝나면 원본 폴더 옆 `폴더명_neko`에 저장돼요

목록에서 썸네일로 결과를 바로 확인할 수 있고, 마음에 안 드는 부분은 **결과 보기·수정** 창에서 직접 고칠 수 있어요:

- 🙈 **검열 지우기** — 자동 감지가 놓친 검열을 꼭짓점 클릭으로 집어 지워요
- 💬 **식자 다시 하기** — 말풍선 위 글자를 그 자리에서 바로 고치고, 옮기고, 크기를 바꿔요 (글꼴·색도 변경)

채색 품질, 검열 감지 민감도, 번역 엔진, 글꼴 같은 세부 조절은 ⚙ 설정에서 할 수 있어요.
더 좋은 채색 모델이 나오면 설정 → 엔진에서 파일이나 주소로 받아 바꿔 끼울 수 있습니다.
