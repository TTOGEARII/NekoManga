# NekoManga (=^･ω･^=)

[English](README.en.md)

흑백 만화에 마법을 부리는 올인원 데스크톱 앱.
이미지를 끌어다 놓고 버튼 하나만 누르면 — 번역·검열 제거·채색까지 알아서 해줍니다.

- 💬 **번역 + 식자** — 말풍선을 읽고(manga-ocr-nar-small) 번역해 깔끔하게 다시 써넣어요. 그림 위나 검은 바탕에 놓인 글은 글자 색과 외곽선 색을 서로 바꿔(흰 글자·검은 외곽선) 읽히게 해요 — ⚙ 설정 → 💬 번역 탭에서 끌 수 있어요. 풍선 밖 효과음은 그대로 두는 것이 기본이고, 같은 탭에서 **지우고 번역으로 덮는다냥 (시험 중)**을 고르면 원문을 지우고 그 자리에 굵은 글씨로 번역을 넣어요(용어집 → 내장 의성어 사전 → 번역기, 세로로 긴 효과음은 글자를 쌓아요). **번역 지침**(같은 탭 — DeepSeek·Grok)에서 이름 뒤 호칭(그대로·자연스럽게·빼기)과 말투를 고르고 인물별 말투·작품 메모를 적어 두면 번역이 그 방향을 따라요. 인물 이름 같은 고정 표현은 **번역 용어집**(한 줄에 하나, 원문=번역)에 적고, DeepSeek·Grok은 앞 페이지 대사를 문맥으로 같이 받아요. 결과 창이나 번역 표로 고친 글은 같은 원고를 다시 돌려도 새 번역으로 덮지 않고(같은 탭에서 끌 수 있어요), 고른 번역기가 못 옮겨 다른 번역기로 메웠거나 끝내 못 옮긴 줄은 ⚠로 표시해요
  - 번역 엔진 선택: **Google**(무료) · **DeepL** · **DeepSeek** · **Grok** — AI 엔진은 문맥을 살려 말투가 자연스러워요
  - 일본식 세로 말풍선도 한국어 가독성에 맞게 가로로, 단어가 중간에 끊기지 않게 배치돼요
  - 말풍선 안의 글만 번역해요 — 풍선 밖 효과음·손글씨는 그대로 두어요 (설정 → 번역에서 끌 수 있어요)
  - 그림 위의 글(풍선 밖 대사·투명 풍선)을 지운 자리가 뿌옇게 남으면 **'지운 자리 다시 그리기'**(시험 중, ComfyUI SDXL)를 켜 보세요 — 그 자리만 주변 그림에 맞춰 다시 그려요. 흰 풍선 안은 그대로 두고, 글자용 체크포인트·ControlNet·프롬프트는 검열 제거와 따로 골라요 (설정 → 번역)
- 🙈 **검열 제거** — [Aletheia Lens](https://github.com/Cec1c/Aletheia-Lens)의 감지 AI가 막대·모자이크를 찾고(가는 흰 막대선은 전용 학습 AI가 보완), 복원 전에 **직접 확인·보정**할 수 있어요
  - 감지 → 검토 창에서 놓친 곳을 칠하거나 잘못 잡힌 곳을 지움 → 복원
  - 복원 방식 3가지: **기본**(Aletheia Lens의 DeepCreamPy 복원, 빠름) / **재생성**(SDXL, 내장 레시피) / **커스텀 ComfyUI**(내가 만든 워크플로)
  - 재생성·커스텀은 검열 조각 자리만이 아니라 **그 조각이 덮은 부위 전체**를 다시 그려요 — 선택 구성요소 '부위 감지 모델'(45MB)이 부위를 찾고, 없거나 못 찾은 조각은 크기의 0.6배로 넓혀요 (설정 → 검열 제거 → 고급 옵션)
  - 재생성은 영역마다 주변을 1024로 잘라 SDXL 두 단계(검열 조각을 새로 그림 → 부위 전체를 다듬음)로 그려요. LaMa는 쓰지 않아요. 첫 단계는 조각에서 검은 막대만 지워 막대 사이로 보이는 윤곽·손을 남겨요. 첫 단계는 원고의 선을 약하게(기본 0.25) 참고해 주변과 이어지게 그려요 — 설정 → 검열 제거 → 고급 옵션의 '조각 그리기 CN 강도'로 바꿀 수 있어요(0이면 참고하지 않아 주변과 안 이어질 수 있고, 높이면 막대 자리가 평평한 흰 칠로 메워지기 쉬워요). 이전 버전의 기본값(0이나 0.5)을 그대로 쓰고 있었다면 업데이트 뒤 첫 실행에 0.25로 바뀌고, 직접 바꾼 값은 그대로예요. 그려도 막대 자리가 평평한 흰 칠로 남는 조각은 새 시드로 두 번까지 다시 그려 덜 흰 쪽을 골라요('흰 조각 다시 그리기', 0이면 꺼요). 부위 태그는 검열 조각마다 남성·여성을 가려서 **한쪽 성별뿐인 범위에는 그쪽 태그만**, 남녀가 같이 있거나 가리지 못한 범위(삽입처럼 가려진 다른 쪽이 있을 수 있거나 부위를 못 찾은 곳)에는 둘을 같이 넣어요 — 어느 태그로 그리는지는 진행 줄에 보이고, 자동으로 못 가린 조각은 결과 창에서 직접 고를 수 있어요 (설정 → 검열 제거 → 고급 옵션에서 바꿀 수 있어요. '자리마다 그 성별의 태그만'을 켜면 남녀가 같이 있는 범위도 조각 쪽마다 따로 넣어요 — 시험 중인 옵션이에요)
  - 검토 창에서 고친 마스크는 학습 재료로 쌓이고, 원하면 앱 안에서 **반자동 자가 학습**으로 감지 모델을 내 작품에 맞춰 갈 수 있어요
- 🎨 **자동 채색** — 흑백 원고를 AI가 풀컬러로
  - **컬러 표지를 등록하면** 캐릭터 머리·눈·의상 색을 표지와 똑같이 맞춰줘요
  - ComfyUI 화면을 앱에서 바로 열고, 거기서 만든 워크플로(API JSON)를 채색·검열 제거에 끼울 수 있어요

모든 AI 엔진은 **앱이 알아서 설치하고, 켜고, 꺼요** — 따로 실행하거나 관리할 프로그램이 없습니다.
번역과 검열 제거(기본)는 작은 내장 모델(약 0.8GB)로 돌아가요. 그래픽카드가 되면 재생성 검열 제거에 쓰는 엔진(ComfyUI, 약 12GB)도 함께 받고,
채색까지 쓰려면 첫 실행 안내에서 **'채색도 설치'(약 5GB 추가)** 를 체크해 두면 끝이에요.
설치할 때 PC를 점검해서 그래픽카드에 맞는 엔진을 고르고, 드라이버·런타임이 모자라면 받을 곳을 바로 알려줘요.
**VRAM·RAM에 맞춰 해상도·메모리 옵션도 자동으로 맞춰** 주니 따로 만질 게 없어요.

## 설치

[최신 버전 받기](https://github.com/TTOGEARII/NekoManga/releases/latest) — `NekoManga-win-Setup.exe`를 받아 실행하세요.
이후 새 버전이 나오면 앱이 알아서 알려주고, 버튼 한 번으로 업데이트됩니다.

### 설치 파일이 실행되지 않을 때

설치 파일에는 코드 서명이 없습니다. 그래서 백신이나 Windows가 처음 보는 파일로 보고 실행을 막거나 붙잡아 둘 수 있습니다.

- **"Windows의 PC 보호" 창이 뜰 때**: [추가 정보] → [실행]을 누르세요.
- **실행했는데 아무 창도 안 뜰 때**: 백신(V3 등)이 실행을 붙잡고 있을 수 있습니다. 먼저 작업 관리자(Ctrl+Shift+Esc)에서 `NekoManga-win-Setup.exe`를 모두 끝내세요. 그다음 백신의 알림 창이나 차단 기록에서 이 파일을 허용하거나 예외(신뢰)로 등록하고 다시 실행하세요.

소스는 이 저장소에 모두 공개되어 있고, 설치 파일은 GitHub Actions가 이 소스로 빌드해 올린 것입니다.

### PC 사양

| | 최소 (번역·식자·검열 제거) | 권장 (채색·재생성까지) |
|---|---|---|
| OS | Windows 10 64비트 | Windows 10/11 64비트 (AMD는 Windows 11) |
| CPU | 쿼드코어 이상 | 6코어 이상 |
| RAM | 8GB | **32GB** (16GB 미만이면 앱이 엔진 미리 켜기를 자동으로 꺼요) |
| GPU | 없어도 동작해요 | **NVIDIA RTX 20 이상** 또는 **AMD Radeon RX 6000 이상**, VRAM 8GB 이상 (GTX 10 이하는 구형 엔진으로 자동 설치, 느려요) |
| 디스크 | 2GB | **25GB 이상** |
| 인터넷 | 최초 모델 다운로드(0.8GB) | 최초 모델 다운로드(약 20GB) |

- NVIDIA는 드라이버 **580 이상**(RTX 20 이상) 또는 528 이상(GTX 10 이하), Visual C++ 2015–2022 x64 런타임이 필요해요 — 설치 창이 검사해서 부족하면 받을 곳을 알려줘요.
- AMD는 ComfyUI 공식 ROCm 포터블을 받아요(초기 지원). NVIDIA보다 느리거나 일부 노드가 안 될 수 있어요.

처리 속도 참고 (RTX 2070 SUPER 기준): 번역+식자 페이지당 약 8초,
검열 제거(기본) 약 2초, 자동 채색 약 2분 30초.
번역·검열 감지·기본 검열 제거는 그래픽카드(DirectML)로 돌려요 — 전용 VRAM이 6GB 이상이고 채색·GPU 검열 제거를 같이 쓰지 않을 때 자동으로 켜지고,
아니면 CPU로 돌아요 (설정 → 엔진 → 내장 AI 가속에서 바꿀 수 있어요).

## 사용법

1. 만화 이미지(또는 폴더)를 창에 끌어다 놓아요 — 이름 순서(1, 2, 10)로 자동 정렬돼요 (이미 돌린 폴더를 다시 올려도 그 안의 결과 폴더 `폴더명_neko`는 건너뛰어요)
2. 원하는 기능 토글을 켜요
3. **✦ 시작!** — 검열 제거를 켰으면 장마다 검열을 찾아요. **검열이 없는 장은 기다리지 않고** 채색·식자까지 바로 끝나고,
   검열이 잡힌 장은 **검토 대기**로 남아요. 목록에서 더블클릭하면 🙈 **검열 지우기** 탭이 열리니, 빨간 곳(지워질 곳)을 확인해 놓친 검열은 칠하고
   잘못 잡힌 곳은 지운 뒤 [검열 제거 시작]을 누르세요 — 대기 중인 장이 전부 진행되고 창이 닫혀요. 일일이 보기 귀찮으면 [대기 중 전부 진행]으로 한 번에 보낼 수 있어요.
   (⚙ 설정 → 검열 제거에서 옛 방식인 "검토 창 — 모든 장을 먼저 찾고 창 하나에서 한꺼번에"로 바꿀 수도 있어요.)
4. 끝나면 원본 폴더 옆 `폴더명_neko`에 저장돼요 — 한 장씩 끝날 때마다 목록 썸네일과 미리보기가 결과물로 바뀌어요

마음에 안 드는 부분은 **결과 보기·수정** 창에서 직접 고칠 수 있어요:

- 🙈 **검열 지우기** — 그 장에 쓴 검열 마스크(빨간 곳)를 브러시(B)·지우개(E)·다각형(L)으로 고친 뒤 [지우기]를 누르면 **이 장만** 검열 제거와 식자를 다시 해요 (기본 / 재생성 / 커스텀 중 선택 — 처음에는 설정의 방식이 골라져 있어요). 채색은 다시 하지 않아요 — 채색된 장은 채색된 그림 위에서 지워요.
  - 여러 장을 고칠 때는 장을 넘기며 고친 뒤(넘길 때 마스크가 자동으로 저장돼요) **[고친 장 모두 다시 렌더링]** 을 누르세요 — 고친 장만 한꺼번에 다시 돌아요 (창이 닫히고 목록에서 진행이 보여요, 설정의 검열 제거 방식 그대로). 끝나면 또 고쳐서 몇 번이든 반복할 수 있고, 메인 창의 [고친 N장 다시 렌더링] 버튼으로도 돌릴 수 있어요.
  - 재생성으로 그린 장에는 그때 쓴 **시드**가 적혀요. 마음에 드는 그림이 나왔으면 '재생성 설정 — 이 페이지만'을 펼쳐 **이 장의 시드 고정**을 체크하세요 — 그 뒤로는 [지우기]·[고친 장 모두 다시 렌더링]·[시작] 모두 그 장을 같은 시드로 그려요 (마스크와 재생성 설정이 같으면 같은 그림이 나와요. 검토를 거쳐 돌린 장에만 적혀요).
  - 모델이 재생성일 때는 마스크 보기에 조각마다 **남·여 표시**가 떠요 — 그 조각을 어느 성별의 태그로 그릴지예요 (`?`는 부위를 못 찾아 남녀 태그를 같이 넣는 조각). 표시를 누르면 남성 → 여성 → 남녀 → 자동으로 바뀌고, [모두 남성]·[모두 여성]으로 한꺼번에 고를 수도 있어요. 고른 것은 그 장에 기억돼서 [지우기]·[고친 장 모두 다시 렌더링]·[시작] 모두 그대로 그려요.
  - 남성이 아닌 조각에는 **사정 표시**도 같이 떠요 — 질내사정 태그는 여성 부위마다 늘 넣지 않고, 질내사정으로 판단한 조각이 있는 곳에만 넣어요. 자동 판단(태그 모델)이 틀리면 표시를 눌러 넣기 ↔ 빼기를 직접 골라요 (설정 → 검열 제거 → 고급 옵션의 '질내사정 태그'·'자동으로 판단해요').
  - 검열 자리가 한 장에 여러 군데 흩어져 주변의 몸이 흐려지거나 달라진다면 설정의 **'떨어져 있는 검열 자리는 따로 다시 그려요'**(시험 중)를 켜 보세요 — 서로 닿지 않는 자리를 따로따로 원래 크기에 가깝게 그려요(그리는 횟수만큼 더 걸려요).
  - 고친 마스크는 결과 폴더의 `.neko`에 남아서 **같은 원고를 다시 돌려도 그대로 쓰여요** (설정에서 끌 수 있어요).
  - 오른쪽 도구 패널은 보기·도구·지우기·마스크 묶음으로 나뉘어 있고, 맨 위 **안내** 카드를 펼치면 단축키 표가 보여요 — B 브러시 · E 지우개 · L 다각형 · [ ] 브러시 크기 · Ctrl+Z 되돌리기 · Ctrl+D 마스크 전부 지우기 · Space+드래그 이동 · Alt+휠·Ctrl+± 확대.
- 💬 **식자 다시 하기** — 실제 식자된 그림 위에서 포토샵처럼 고쳐요. 풍선을 클릭해 고르고, 끌어 옮기고, 여덟 방향 손잡이로 늘리고, 위쪽 동그란 손잡이로 돌려요. 두 번 클릭하면 그 자리에서 글과 줄 나눔을 고치고(Enter = 줄 나눔), [＋ 새 글 넣기]로 효과음·빠진 대사를 직접 넣어요. 고른 풍선의 원문(OCR이 읽은 글)이 번역 글 칸 위에 보이고 그림 위 풍선에 마우스를 올려도 떠서, 번역을 고칠 때 원문을 보며 고쳐요. 원문 칸과 번역 글 칸은 글이 길면 칸이 그만큼 늘어나고, 풍선 목록은 글이 폭에서 잘리면 "…"이 붙어요(마우스를 올리면 온 글). 고른 풍선만 글꼴·크기(px)·색·외곽선(px)·정렬·회전을 바꿀 수 있고, 한 풍선을 고쳐도 다른 풍선의 글자 크기는 그대로예요. Ctrl+Z 되돌리기 · Ctrl+Y 다시 실행 · Delete 고른 풍선 숨기기 — 이 탭의 **안내** 카드에도 조작법이 있어요. 여러 장을 한꺼번에 고치려면 메인 창 [📑 번역 표]로 번역을 CSV로 내보내 엑셀에서 '번역' 칸을 고친 뒤 들여오세요 — 고친 장만 다시 식자돼요.

채색 품질, 검열 감지·복원 방식, 번역 엔진, 글꼴 같은 세부 조절은 ⚙ 설정에서 할 수 있어요.
더 좋은 채색 모델이 나오면 설정 → 엔진에서 파일이나 주소로 받아 바꿔 끼울 수 있고,
PC를 바꿨다면 설정 → 엔진의 **[이 PC에 맞게 조정]**으로 해상도·메모리 옵션을 다시 맞출 수 있어요.

화면 언어는 설정 → 정보의 **🌐 화면 언어**에서 한국어 · English · 日本語 중에 골라요 — 처음 켤 때는 Windows 언어를 따라가고(한국어·일본어가 아니면 영어), 고르는 즉시 바뀌어요.
만화를 옮기는 언어(설정 → 번역)와는 따로예요.

## ComfyUI를 쓰는 분께

- 설정 → 엔진 → **ComfyUI 화면 열기**로 앱이 내장한 ComfyUI를 브라우저에서 열 수 있어요 (모델·노드·큐를 앱과 공유).
- **내장 재생성 레시피를 ComfyUI에 넣기**로 앱의 검열 제거 워크플로를 ComfyUI 워크플로 목록에 복사해 출발점으로 쓰세요.
- 고친 워크플로를 **Export (API)** 로 저장하면 검열 제거(커스텀 ComfyUI)나 채색(채색 커스텀)에 그대로 끼울 수 있어요.
  규칙은 둘뿐: LoadImage 하나(앱이 원고를 넣어요, 검열 제거면 알파 = 마스크), SaveImage 하나(결과).

## 고마운 프로젝트

- 글자 읽기: [manga-ocr-nar-small](https://huggingface.co/muscgab/manga-ocr-nar-small) — 일본어 만화 말풍선을 한 번에 읽는 빠른 OCR이에요(손글씨·효과음도 잘 읽어요). **모델 가중치는 CC BY-NC-SA 4.0(비영리)** 이에요 — NekoManga는 비영리 개인 프로젝트라 그 조건에 따라 모델 릴리스에 바꾸지 않고 다시 올려 두었어요(라이선스 전문·고지 포함). 상업적으로 쓰신다면 설정 → 번역 → 글자 읽기 엔진에서 다른 엔진을 고르세요.
  고를 수 있는 다른 엔진: [Hayai OCR v2.7 Supernova](https://huggingface.co/JustANormalTinkerer/hayai-ocr-v2.7-supernova) (Apache-2.0 — 느리지만 상업적으로도 쓸 수 있어요) · manga-ocr(이전 엔진).
- 검열 감지·기본 복원: [Aletheia Lens](https://github.com/Cec1c/Aletheia-Lens) (GPL-3.0) — 그 프로젝트의 감지(hent-AI Mask R-CNN)·복원(DeepCreamPy) 처리 과정을 C#으로 옮겨 쓰고, 모델은 그 프로젝트가 배포하는 파일을 그대로 받아 써요.
  바탕이 된 [hent-AI](https://github.com/natethegreate/hent-AI) · [DeepCreamPy](https://github.com/cookieY/DeepCreamPy) · [Mask R-CNN](https://github.com/matterport/Mask_RCNN)에도 감사드려요.
